Em grupos de até 4 alunos, deve ser desenvolvido um sistema de Backend Rest com os seguintes requisitos:

- autenticação externa (sugestão Firebase)

- Uso de JWT

- usando framework Express

- Consumindo um SGBD externo na núvem ou em um container

- Rotas Rest para CRUD

- Divisão em microserviços (opcional)

- Publicação na internet (opcional)
